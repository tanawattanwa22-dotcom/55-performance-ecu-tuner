FTDI / Honda ECU LAB

พอร์ตคำสั่งระบุรหัส ECU จาก C# ต้นฉบับและเครื่องมือตรวจแพ็กเก็ตเขียนแฟลชแบบออฟไลน์

ขอบเขตที่ทำได้จริง

โมดูลนี้สื่อสารผ่าน WebUSB กับ FT232R 0403:6001 จริงเมื่อเลือกสาย และมีโหมดอ่านรหัส ECU แบบไม่ลบหรือเขียนหน่วยความจำ คำสั่งปลุก ECU ยังไม่ได้รับรองกับทุกกล่อง

ไม่มีคำสั่ง ERASE, WRITE หรือ VERIFY บนสายจริงในหน้านี้ ห้ามนำไปใช้แฟลช ECU รถลูกค้าจนกว่าจะตรวจโปรไฟล์ ECU และทดสอบกับกล่องสำรองเรียบร้อย

1. ตรวจสิทธิ์ Supabase

กำลังตรวจสิทธิ์จาก Supabase...
ต้องล็อกอินและเปิด License Key บนเครื่องนี้ผ่านแอป ECU Tuner ก่อน

2. เชื่อมต่อ FT232R ด้วย Chrome Android

ขั้นนี้เสียบเฉพาะสาย FTDI + OTG กับมือถือได้ ยังไม่ต้องต่อกล่อง ECU

ยังไม่เชื่อมต่อ
รองรับชิป FT232R VID 0403 PID 6001 ที่ยืนยันการเข้ารหัส Baud Rate แล้ว ชิปตระกูลอื่นต้องตรวจแยก

3. ตรวจ ECU ID (อ่านอย่างเดียว)

ใช้ ECU สำรองและวงจร K-Line ที่ตรวจขั้วและแรงดันแล้วเท่านั้น อย่าต่อ FTDI TTL เข้าขา K-Line 12V โดยตรง

ยังไม่ได้อ่าน ECU
ลำดับทำงานตาม C#: InitFtdiIso → WAKE → HELLO → ECU ID; ล้มเหลวจะปิด USB ไม่เดาคำสั่งอื่น

4. ตรวจ BIN และแพ็กเก็ตจาก C# (ออฟไลน์)

นำไฟล์ .bin จากมือถือมาตรวจว่าฟังก์ชันสร้างแพ็กเก็ตเขียน (64/128 byte) สอดคล้องกับสูตร C# หรือไม่ ไม่ส่งข้อมูลไป ECU หรือเซิร์ฟเวอร์
