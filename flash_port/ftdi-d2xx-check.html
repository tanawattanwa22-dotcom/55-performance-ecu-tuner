55 PERFORMANCE · D2XX → WebUSB Driver Check

แปลงคำสั่งจาก Windows FTD2XX_NET.dll บางส่วนเป็น JavaScript สำหรับ FT232R โดยใช้ WebUSB จริง ไม่สามารถโหลด DLL ลง HTML และไม่ใช่ตัวจำลอง ECU

ถอดสายด้าน ECU และปิดแท็บที่ใช้ FTDI อยู่ก่อนตรวจ หน้านี้ ไม่ส่ง WAKE / ECU ID / ERASE / WRITE

ยังไม่เชื่อมต่อ



รายละเอียดความเข้ากัน


FT_GetQueueStatus และ FT_Read ของ Windows D2XX ไม่สามารถใช้แบบเดิมในเบราว์เซอร์ ต้องใช้การอ่าน Echo/ACK ของ WebUSB ที่มีอยู่ในโปรแกรมแทน ผลตรวจ USB ผ่าน ไม่ได้แปลว่าแฟลช ECU ได้แล้ว
