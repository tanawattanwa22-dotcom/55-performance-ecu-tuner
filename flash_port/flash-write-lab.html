BENCH V16.1 — กล่องสำรอง

มีการส่งคำสั่ง ERASE/WRITE จริง!

เครื่องมือนี้ใช้โค้ด C# ที่ซื้อมาเป็นต้นแบบและเปิดเฉพาะ ECU ID ที่จับคู่กับฐานข้อมูลเดิมแล้วเท่านั้น พอร์ตฐานข้อมูล C# เดิม 288 รายการ และอนุญาตทดลองเขียนเฉพาะกล่อง Keihin ที่อ่าน ECU ID ตรงฐานต้นฉบับ ผ่านการตรวจแฟลชเคานต์และโปรไฟล์ข้อมูล (ตัวอย่าง K03-H01 รหัส 0101880D01 • ทั้ง Keihin และ Shindengen ต้องผ่านการยืนยันรายรุ่น)

ยังไม่เคยยืนยันเขียนบนกล่องจริงของนาย ฟังก์ชัน Verify ในซอร์สต้นฉบับเป็น ACK ปิดเซสชัน **ไม่ใช่การอ่านแฟลชกลับทั้งก้อน** อุปกรณ์สำรองก็สามารถเสียหายถาวรได้

สาย FTDI TTL ห้ามต่อเข้าขา K-Line 12V โดยตรง ต้องมีวงจร K-Line transceiver/แหล่งจ่ายที่ถูกต้อง และอุปกรณ์กู้คืนที่ทดสอบแล้ว
