55 PERFORMANCE — ตรวจสอบว่าสาย USB รุ่นใด

หน้าอ่าน USB แบบปลอดภัย: ตรวจเฉพาะตัวระบุ VID/PID และ USB descriptors ไม่เปิดพอร์ต ไม่ส่ง Wake/READ/ERASE/WRITE และไม่สื่อสารกับ ECU หรือ K-Line

ยังไม่ได้ตรวจสาย USB

ต้องเปิดผ่าน Chrome Android / HTTPS พร้อม USB OTG

ทำความเข้าใจผล

โปรแกรมเขียนแฟลช 55 Performance ปัจจุบันรองรับอุปกรณ์ที่ระบุ VID 0403 / PID 6001 (FT232R) เท่านั้น หากสายรายงาน PID อื่น โค้ดจะปฏิเสธ แม้จะเป็นสาย FTDI บางรุ่นก็ตาม

USB ผ่านไม่ได้แปลว่า ECU หรือสาย K-Line เสีย และ USB ผ่านก็ไม่ได้พิสูจน์ว่าสาย K-Line/ECU ตอบสนองถูกต้อง ห้ามขยายรายการสายโดยเดา โปรดตรวจวงจรแปลงระดับและโปรโตคอลก่อนใช้กับรถจริง
