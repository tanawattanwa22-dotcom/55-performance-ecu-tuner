55 PERFORMANCE — ตรวจสิทธิ์ USB ของ Android

ทดสอบเฉพาะการเปิด/ปิด USB: อ่าน VID/PID แล้วทดลอง USBDevice.open() และ close() โดยไม่ Claim Interface ไม่ตั้ง Baud ไม่ส่ง Wake/READ/ERASE/WRITE และไม่สื่อสารกับ ECU หรือ K-Line

ให้ถอดสายที่ต่อเข้า ECU ออกก่อนทดสอบ หน้านี้ใช้ตรวจเฉพาะ FT232R + OTG กับมือถือ

จากภาพ Honda Tuner: Chrome แสดง FT232R (A965S6NF) (0) และ (2) แม้ Serial ซ้ำกัน ให้ปิดพอร์ตในเว็บ Honda Tuner ก่อน แล้วเลือกอุปกรณ์แถว (2) ในหน้าต่าง Android เอง (JavaScript อ่านหมายเลขรายการ Android ไม่ได้)

ยังไม่ได้ตรวจสาย USB

ต้องเปิดผ่าน Chrome Android / HTTPS พร้อม USB OTG

ทำความเข้าใจผล

โปรแกรมเขียนแฟลช 55 Performance ปัจจุบันรองรับอุปกรณ์ที่ระบุ VID 0403 / PID 6001 (FT232R) เท่านั้น หากสายรายงาน PID อื่น โค้ดจะปฏิเสธ แม้จะเป็นสาย FTDI บางรุ่นก็ตาม

หากเลือกสายสำเร็จแต่ open() ขึ้น SecurityError: Access denied แสดงว่าเปิด USB ไม่ได้ตั้งแต่ระดับเบราว์เซอร์/Android ไม่เกี่ยวกับคำสั่ง ECU เว็บไม่สามารถบังคับแสดงหน้าต่างสิทธิ์ของ Android เองได้

หากยังไม่ขึ้นหน้าต่างขอสิทธิ์ ให้ลองเปิดใน Chrome เต็มหน้าจอ (ไม่ใช่หน้าต่างเบราว์เซอร์ภายในแอป), ปิดแอปอื่นที่ใช้ USB และถอด OTG ก่อนเปิดใหม่ หากยังไม่สำเร็จให้รีสตาร์ตมือถือโดยถอด OTG ออกก่อน แล้วเชื่อมอีกครั้ง

USB เปิดผ่านก็ไม่ได้พิสูจน์ว่าสาย K-Line หรือ ECU ตอบสนองถูกต้อง ห้ามใช้ผลนี้อนุญาต ERASE/WRITE
