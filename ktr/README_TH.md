# 55 PERFORMANCE — ฐานข้อมูล ECM Honda

บันทึกข้อมูลจากภาพที่ผู้ใช้ส่งวันที่ **2026-11-02** (1024 × 1536 พิกเซล) เป็นฐานอ้างอิง ไม่ใช่ไฟล์ BIN/XDF หรือการรับรองการแฟลช ECU

## ที่มาและการตรวจสอบ

- ภาพต้นทาง: **ตารางรายการ ECM Honda ที่เจ้าของแอปนำเข้าระบบ** (บันทึกชื่อเจ้าของข้อมูลต้นฉบับไว้ใน metadata เพื่ออ้างอิงย้อนกลับ)
- SHA-256 ของไฟล์ JPG ที่ผู้ใช้ส่ง: `1c3217133650d83d22694d25437347d274a2cdbbf29841e87f9502a9024365d4`
- จำนวนที่ถอดข้อมูลจากภาพ: **152 แถว**, **56 กลุ่มรุ่นรถ**
- **124 แถว** มีรูปแบบ ECM ID / Part Code ครบ แต่ยังไม่ถือว่ายืนยันกับกล่องจริง
- **38 แถว** มีตัวอักษรบางส่วนเล็ก/พร่า หรือชื่อกลุ่มไม่ชัด จึงทำเครื่องหมาย `reviewRequired=true` และปล่อยช่องที่ไม่มั่นใจเป็น `null`
- Keihin **107** แถว, Shindengen **45** แถว
- ขนาด BIN ตามตาราง: 48, 56, 64, 96, 128, 256, 384 และ 768 KB
- ***ไม่มีการเดา ECM ID 10 หลักในรายการที่อ่านไม่ชัด***; บางชื่อกลุ่มขวาล่างยังต้องใช้ภาพต้นฉบับความละเอียดสูงกว่าเพื่อยืนยัน

## ตำแหน่งบันทึก

- ชุดข้อมูล GitHub: `ktr/ecm-catalog.js` (สำเนาใช้เมื่อออฟไลน์)
- หน้าค้นหาแบรนด์ 55 Performance: `ecm/index.html` (เปิดจากเมนูหน้าจูนหลัก)
- ลิงก์เดิม `ktr/index.html` ยังคงไว้เพื่อนำผู้ใช้ไปที่หน้าแบรนด์ใหม่โดยอัตโนมัติ
- Supabase โปรเจกต์เดิม **55-performance-ecu**: `public.ecu_ktr_reference`
- Supabase มี RLS เปิด, นโยบาย SELECT-only; ไม่อนุญาต INSERT/UPDATE/DELETE สำหรับ anon/authenticated
- หน้าเว็บลองอ่านข้อมูล Supabase ก่อน และถ้าเครือข่ายล้มเหลวจะใช้ข้อมูล GitHub ชุดนี้แทน

**หมายเหตุการเปลี่ยนแบรนด์:** หน้าแอปและ URL แสดงชื่อ **55 Performance** โดยไม่เปลี่ยนรหัสแถวอ้างอิงเดิมหรือชื่อฐาน Supabase ที่ระบบใช้ ข้อมูลต้นฉบับเป็นข้อมูลอ้างอิงภายนอก ไม่ใช่ตารางที่ 55 Performance ตรวจวัดหรือรับรองเอง

## ขอบเขตที่สำคัญ

ข้อมูล ECM ID, Part Code, ชนิดกล่อง และขนาด BIN ในรูป **ไม่ใช่** BIN, XDF, ADX, Checksum Offset, Start Offset ที่ยืนยันแล้ว หรือโปรโตคอลแฟลช

**ห้าม** นำทะเบียนนี้ไปอัปเดต `ecu_model_data`, `flash_port/csharp-ecu-catalog.js` หรือปลดล็อก ERASE/WRITE อัตโนมัติ

รายการ K2J-T01 / K2J-TH1 ในรูปเป็นเพียงข้อมูลอ้างอิง จนกว่าจะมี ECM ID จริง, BIN/XDF ที่ตรวจตรงกัน และหลักฐานโปรโตคอลจาก ECU สำรอง

นำรูปต้นฉบับความละเอียดสูงกว่ามาอ้างอิงเฉพาะช่องที่ไม่ชัด แล้วปรับ `ecuId`, `partCode`, `reviewRequired` ในชุด GitHub และ Supabase ให้ตรงกัน หลังแก้ให้รันชุดทดสอบและตรวจนับแถวซ้ำ ห้ามเติมตัวอักษรโดยคาดเดาจากรุ่นรถ
